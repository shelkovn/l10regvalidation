# Registration Validator

Учебный проект — валидация данных пользователя при регистрации.

## Форматы логина

- **Телефон**: `+X-XXX-XXX-XXXX`
- **Email**: `xxx@xxx.xxx`
- **Строка**: латиница, цифры, `_` (мин. 5 символов)

## Требования к паролю

- Мин. 7 символов
- Только кириллица, цифры, спецсимволы
- 1 заглавная + 1 строчная + 1 цифра + 1 спецсимвол
- Пароль = подтверждению

## Логирование

- В файл `log.txt`
- В консоль
- Пароль маскируется как `***`

## Использование

```csharp
var result = RegistrationValidator.Validate(
    login: "user_123",
    password: "ПрИв1!",
    confirm: "ПрИв1!"
);
// result = (true, "") или (false, "текст ошибки")
```

## Возможные ошибки
- Неверный формат телефона/email
-Короткий логин или пароль
- Недопустимые символы
- Логин из чёрного списка
- Не совпадают пароли
- Отсутствие заглавной/строчной буквы, цифры или спецсимвола
